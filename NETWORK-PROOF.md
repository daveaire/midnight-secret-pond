## Reproduce

With Docker Desktop and the Compact compiler installed:

```sh
npm install
npm run network:setup
npm run network:prove -- --route synthetic-hackathon-route-1 \
  --net-bps 80 --bridge-seconds 600 --liquidity-usd 25000
```

`network:setup` starts the pinned local node, indexer, and proof server, compiles the contract, and deploys it. `network:prove` synchronizes the wallet, generates the proof, submits the transaction, waits for finalization, queries the indexed contract state, and prints only public results.

For Preview, start the local proof server, fund the address printed by `network:address`, and use the public network commands documented in `README.md`. The route string is hashed locally; only transaction metadata, the accepted-proof count, and the public commitment are printed.
